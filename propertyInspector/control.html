PhotoCraft Edit Control

Works with the open PhotoCraft document through its authenticated local control channel. Start it with --control 7878 --control-token-file /private/path/token.

The token itself is never stored in the Stream Deck profile; the plugin reads this local file only when it runs.

Exposure, contrast, and vibrance knobs update the selected matching adjustment layer non-destructively. The key actions above create Exposure and Vibrance layers quickly.

Configure a control and place it on a key or encoder.
